# 启伴·一键启动器 v0.3.1

Windows x64 免安装版。下载 `Qiban-0.3.1-Windows-x64.zip`，完整解压后运行 `QuickLauncherWinUI3.exe`。Source code 是源码，不是可运行安装包。

## 本版变化

- 独立“主目录”展示全部软件，支持全部/未分组/已分组筛选、搜索、排序和批量归入分组。
- 主目录自动收录，扫描目录与非应用程序排除名单可在设置中维护。
- 勾选批量删除记录、整行勾选与框选、分组间复制/剪切，显示完整路径与后缀。
- 设置统一管理主题、背景、备份、更新记录；公开更新无需登录或填写令牌，下载安装包后校验 SHA256。

## 安装与升级

包含 .NET 和 Windows App SDK。更新前正常关闭启伴，备份 `launcher_config.json`、`Backgrounds/` 与日志，把 ZIP 中的完整程序文件夹合并至原目录并保留个人数据。不要只替换 EXE。

旧“自动收录”记录会迁到独立主目录，普通分组保留。启动器不自动覆盖安装程序；可在“设置 → 检查版本更新”中检查和下载后续版本。

发行包从独立源码构建，不含维护者配置、软件清单、运行日志或个人背景副本。公开前检查记录见仓库文档。

## 验证与限制

已完成 Release x64 构建与独立逻辑检查；公开更新请求、发行包校验和数据保留另行核对。新电脑兼容性、全部 Windows 版本和完整界面操作仍需持续验证；没有数字签名。其他限制与素材说明见包内文档。
