- 未发现维护者的配置文件、软件盘点清单、真实用户目录/工作区路径、桌面截图、运行日志或常见格式密钥进入已核查的提交历史与发布源码。
- 两个历史提交的作者和提交者使用 GitHub noreply 邮箱，没有暴露私人邮箱。
- 本地 v0.1.0-beta ZIP 的 SHA256 与 GitHub 发行资产一致；核查包中全部文件名，以及本项目构建的程序集、资源和文本文件，未发现维护者个人数据。
- 新版 v0.3.1 从独立源码构建，同样完成包内 469 个条目的文件名及项目自有内容检查，未发现维护者个人数据；原始第三方署名保留。
- 依赖清单中的四段程序集版本号不是网络地址；第三方许可证中的公开作者邮箱属于原始署名，按原样保留，不作为维护者个人信息删除。
- 无需删除或重写历史提交；旧 beta 的“私有测试”文案是当时的历史说明，当前使用方式以最新版 README 与发行记录为准。

## 持续防护

- `.gitignore` 采用允许清单，运行配置、发布目录、背景副本、日志、验证材料和构建产物均不提交。
- `scripts/Audit-Privacy.py` 可对指定的 Git 可达历史、待提交文件及发行 ZIP 进行只读检查；报告只列命中类型与位置，不输出命中内容。须人工判断误报。
- 发行脚本从独立源码目录构建，禁止带入配置、缓存、日志、个人背景副本或调试符号；使用相对源码映射，附带第三方声明及校验文件。
- 公开版更新请求不携带令牌，不上传软件清单和配置；用户运行数据保留在本机。

检查结果只覆盖所列历史与产物，之后新增文件、分支或发行包需要再次核查。本记录不替代第三方素材和组件的许可证说明。
