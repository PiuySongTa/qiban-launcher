# 启伴·一键启动器 v0.1.0-beta

首个 Windows x64 免安装测试版。

## 下载与运行

下载 **Qiban-0.1.0-beta-Windows-x64.zip**，完整解压后运行 `QuickLauncherWinUI3.exe`。
GitHub 自动附带的 Source code 压缩包是源码，不是可运行软件。

已包含 .NET 8 与 Windows App SDK。建议先在 Windows 11 x64 测试；目标最低系统为 Windows 10 1809 x64，尚未完成全版本验证。其他依赖与首次启动说明见压缩包中的 `使用说明.txt`。

## 功能

- 软件分组、扫描添加、读取已安装应用，以及按名称/后缀/路径搜索。
- 整行勾选、鼠标框选、批量启动与分组间复制/移动。
- 多层目录筛选、排序、深浅主题和背景设置。
- 普通启动默认不强制管理员权限；启动后取消勾选默认关闭。

## 数据与更新

发行包不含维护者的个人配置、软件清单、日志或缓存。首次运行按本机环境建立配置。
更新前关闭程序并备份 `launcher_config.json` 与 `Backgrounds/`，不要直接删除旧版个人数据。

## 已知限制

beta 版本，未完成新电脑和全部 Windows 版本验收；尚无数字签名、自动更新和多实例配置冲突保护。部分旧保存入口的失败反馈、日志轮换、批量启动响应及完整键盘访问仍待完善。
