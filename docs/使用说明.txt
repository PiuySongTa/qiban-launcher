启伴·一键启动器 v0.1.0-beta

开始使用
1. 将整个压缩包解压到自己有写入权限的固定文件夹，例如 D:\Apps\Qiban。
2. 运行 QuickLauncherWinUI3.exe。不要在压缩包内直接运行，不要只复制 EXE。
3. 创建分组，点击“扫描并添加软件”或“添加软件”，选择本机的软件。
4. 勾选要启动的条目，再点击“启动勾选”。双击条目会直接启动该项。

系统与依赖
- 本包面向 Windows 10 1809 及以上的 x64 系统；主要使用环境为 Windows 11。
- 已包含 .NET 8 运行时和 Windows App SDK，无需安装开发工具。
- 未完成无开发环境的新电脑兼容性测试。若提示缺少 VCRUNTIME/MSVCP，
  请从微软官网安装 Visual C++ v14 x64 运行库：
  https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist
- 本测试版尚无数字签名；请核对下载来源和压缩包 SHA256，不要关闭系统安全功能。

数据与备份
- 分组和设置位于程序旁的 launcher_config.json；日志在 logs 文件夹。
- 首次运行不包含作者的个人软件清单；如本机存在 AppGroup 配置，会尝试迁移。
- 可以通过“备份”导出配置；自选背景需一并保留 Backgrounds 文件夹。
- 换电脑后，原软件路径可能失效，需要重新添加。
- 更新前先关闭启伴并备份配置；将新版解压到新目录，按需迁移配置与背景。
- 不要同时打开多个启伴实例编辑同一份配置。
