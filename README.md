# 启伴·一键启动器

一个面向 Windows 的个人应用启动器。按分组整理软件，勾选后批量启动，也可以双击启动单项。

## 下载使用

普通用户请前往 [Releases 发行版](https://github.com/PiuySongTa/qiban-launcher/releases)，下载 `Qiban-版本-Windows-x64.zip`，完整解压后运行 `QuickLauncherWinUI3.exe`。不要下载 Source code 作为可运行软件。仓库公开后无需 GitHub 登录即可下载。

当前公开版为 `v0.3.1`，历史首版为 `v0.1.0-beta`。详见 [使用说明](docs/使用说明.txt)；已内置 .NET 和 Windows App SDK，尚未完成新电脑兼容性验收。个人配置不随发行包提供。

## 功能

- 手动添加软件、拖放文件、扫描桌面/开始菜单/指定目录，以及读取 Windows 已安装应用。
- 显示名称、后缀和完整路径，支持搜索、排序、整行勾选及鼠标框选。
- 目录树包含/排除筛选；启动涉及搜索隐藏的勾选项时明确确认。
- 单条或批量复制/移动到其他分组，以完整路径去重，保留启动参数与管理员设置。
- 勾选批量删除启动器记录，不删除原文件；隐藏的勾选项会明确列出。
- 独立主目录按保存的目录范围收录全量软件，支持未分组筛选、归类及扫描排除名单。
- 深浅主题、可莉默认背景、透明磨砂、自选图片、图片遮罩设置。
- 管理员启动、启动后取消勾选均默认关闭；保留单项管理员设置。

## 版本与更新记录

当前源码版本为 **0.3.1**。主窗口左下方显示版本，“设置”中可查看离线记录或检查 GitHub 版本更新，完整历史见 [更新记录](CHANGELOG.md)。支持显示更新说明、下载并校验安装包；安装采用关闭程序后手动合并完整文件夹的方式。公开版无需登录或填写令牌；检查和下载不会上传个人软件清单或配置。

## 环境与构建

主项目位于 `一键启动器WinUI3/`，使用 .NET 8、WinUI 3 / Windows App SDK 1.6，目标平台 x64。需在具备相应 Windows 构建工具的环境下编译。

```powershell
dotnet restore 一键启动器WinUI3/QuickLauncherWinUI3.csproj -p:Platform=x64
dotnet build 一键启动器WinUI3/QuickLauncherWinUI3.csproj -c Release -p:Platform=x64 --no-restore
```

运行构建输出中的 `QuickLauncherWinUI3.exe`。程序采用完整文件夹分发方式，请保留输出文件，不要只复制 EXE。

维护者可用 PowerShell 7 执行 `./scripts/Build-Release.ps1 -Version 0.3.1` 生成免安装包；可通过 `-Dotnet` 指定 SDK 路径。脚本在独立目录构建，生成 `artifacts/` 下的 ZIP 与 SHA256，不读取个人发布目录、不覆盖配置。发行前还需完成脱敏和实际运行验收。

## 使用

创建分组后添加软件。复选框决定批量启动对象，右键定位行与勾选相互独立。

单条整理：右键记录，选择复制/移动到分组。批量整理：勾选后点击“整理勾选”。新增目标记录默认不勾选；重复路径跳过，移动时跳过记录保留在原组。

批量删除：勾选后点击“删除勾选…”，核对确认列表。删除只影响启伴记录，不影响原文件。单条删除仍可使用右键菜单。

“设置”统一提供主题、背景、半透明面板、扫描范围、扫描排除名单、自动收录、备份和版本记录。背景中的“可莉（默认）”使用内置图片，等比完整显示；遮罩浓度越高，背景越淡。透明磨砂效果由 Windows 管理。

“主目录”独立显示全量软件，普通分组仍在下方。旧“自动收录”的记录与勾选自动迁入主目录；所有普通分组的程序也会按完整路径汇入主目录展示，原分组不变。支持全部/未分组/已分组筛选、搜索、排序和查看所属分组。从主目录归入分组会保留全量，未分组视图会隐藏归类完成的项目；普通分组间移动仍为剪切。

主目录在启伴打开时以及运行期间每 5 分钟刷新，合并新增的程序，新条目不勾选，不自动删除已有记录。也可在设置中手动刷新；关闭自动刷新后主目录保留。旧版本临时扫描的目录未持久化，需要在设置中补充。

非应用程序白名单是扫描排除名单：每行一个准确文件名、完整文件/文件夹路径或已安装应用名称，不支持通配符。目录规则包含全部下级；同名不同路径的文件要分别保留时，请用完整路径。规则仅影响后续扫描，不删除已有记录，也不限制手动添加。主目录中删除的记录如果没有被排除，或仍被普通分组引用，之后可能再次出现。

“设置 → 检查版本更新”匿名读取公开仓库最近 100 条 Release，比较正式版或勾选后的测试版，无需登录或填写令牌。若没有较新的 Windows x64 包，会明确提示；网络错误或限流不会冒充“已是最新版”。下载先写临时文件，核对大小与 SHA256 后才提交，失败不覆盖原下载文件；关闭弹窗可取消。

安装时关闭启伴，先备份 `launcher_config.json`、`Backgrounds/` 和日志，再把 ZIP 中的完整程序文件夹合并到旧程序目录。保留个人文件，不仅替换 EXE。当前版本采用手动合并完整文件夹安装。

## 数据与隐私

用户配置在程序目录的 `launcher_config.json`，日志在 `logs/`。自选背景副本在 `Backgrounds/`，图标缓存位于当前用户的本地应用数据目录。上述运行数据不提交至本仓库。

仓库不包含个人分组、应用盘点、桌面截图、真实路径记录、日志、配置备份、编译产物或历史独立项目。克隆后不会获得原维护者的软件清单。

## 验证与已知限制

纯逻辑验证位于 `tests/LogicChecks/`，不启动用户应用、不访问真实软件清单：

```powershell
dotnet run --project tests/LogicChecks/LogicChecks.csproj
```

目前仍需继续改进：部分旧配置写入入口的失败反馈、多实例配置冲突保护、日志保留策略、完整键盘覆盖，以及批量启动过程的界面响应。详见 [已知限制](docs/已知限制.md)。
